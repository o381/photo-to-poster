# Contributing

Contributions are welcome — a sharper rule, a format the Skill is missing, a field report from a platform where it ran.

**Please keep three things intact:**

1. **One file, in English.** The Skill is a single `SKILL.md`. Anything that cannot survive as one file does not belong in it.
2. **Finished pieces only.** Written cases in the Skill stay generalised design logic, in words. The `examples/` gallery is for finished posters only — no drafts, work files, or project details.
3. **No invented facts, anywhere.** Not in examples, not in sample copy, not in ornament text. If a sample needs a year, a place, or a number, use one a photograph could actually show — or mark it as the user's to supply.

**Field reports are the most valuable contribution.** If you run the Skill and the output is title-only, repetitive, or repaints the photograph, open an issue and describe: the host/platform, the environment tier (A/B/C in the Skill), the kind of photograph, and what the output did. Fixes are made against real outputs, not guesses.
