# Changelog

## 2.1.1 — Example gallery

- Added six finished posters as showcase examples under `examples/`, embedded as a gallery in both READMEs.

## 2.1.0 — Open-source edition

The Skill, cleaned and generalised for public release:

- Case examples are now generalised design logic. Project-specific titles, place names, and identifying details were removed; the techniques they taught are unchanged.
- Removed framing that assumed a specific commissioning history ("a client who has already rejected…", "work the client approved"). The quality bar is now stated directly, so the Skill reads correctly for any user, on any first run.
- Resolved an internal contradiction: the vintage-print "vertical year stack" is now explicitly limited to a year actually visible in the photo or supplied by the user, consistent with the no-invented-facts rule.
- Reframed the "remove one accessory" rule so it can no longer be misread as permission to strip a design back to a bare headline: cut only the piece with no job, and never below the recipe's minimum richness.
- Clarified the compositing snippet in the execution section (the alpha and color variables are now defined in the text).
- Verified clean: no personal names, no conversation or platform references, no local paths, no file identifiers, no dates of creation embedded in the Skill.

## 2.0.0 — The recipe redesign

Rebuilt around a creative recipe — **Format + Type move + Ornament set + Palette + Hierarchy** — after field tests showed the previous version produced title-only, near-identical results:

- Eleven formats (magazine cover, vintage print, zine collage, cinema one-sheet, field-guide plate, paper-frame book, postcard, Swiss grid, panel split, typographic monument, dreamy editorial), each with its own ingredients.
- A full ornament vocabulary in six families, with rules: purposeful, physical, limited, never invented facts.
- An anti-sameness protocol: name the model's default, draft three formats, reject the closest to the default.
- The image-model-only prompt template now specifies the full recipe, ornaments included.
- Original-photo protection, one image per run, and the final self-check retained from 1.0.

## 1.0.0 — First version

One big visual verb plus a headline; taste principles; cheap-design tells; execution tiers for code agents, image models, and prompt-only use. Superseded by 2.0: its restraint rules suppressed nearly all ornament, which is exactly what 2.0 set out to fix.
